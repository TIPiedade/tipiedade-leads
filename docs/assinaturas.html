Instalar

  1. Carrega em Copiar assinatura.
  2. No Outlook: Ficheiro → Opções → Correio → Assinaturas, cria uma nova e cola com Ctrl+V.
  3. No Gmail: Definições → Ver todas as definições → Assinatura e cola.

Guia · Alojar as imagens no GitHub

Faz-se uma vez. Depois, para cada pessoa nova, só se carrega a foto. Serve para as imagens aparecerem em qualquer programa de e-mail (Outlook, Gmail, telemóvel) sem irem como anexo.

1 · Primeira vez
  1. As imagens comuns (logótipo, banner, ícones) já estão alojadas no portal, em tipiedade.github.io/tipiedade-leads/assinaturas/. Não é preciso criar nada.
  2. Escolhe o modelo e preenche os dados. Em Imagens, deixa Alojadas.
  3. Carrega em Preencher e confirma que a pré-visualização mostra todas as imagens.
  4. Copiar assinatura e cola no Outlook ou no Gmail (ver passos em Instalar).
2 · Assinatura para uma pessoa nova
  1. Preenche os dados da pessoa. No modelo Moderno, escolhe e recorta a foto.
  2. Modo Alojadas → Descarregar foto recortada. O ficheiro vem com o nome da pessoa (ex.: joana-silva.jpg) — não mudes o nome.
  3. No GitHub, repositório tipiedade-leads → pasta docs/assinaturas → Add file → Upload files → arrasta a foto → Commit changes.
  4. Espera 1 minuto, carrega em Preencher e depois em Copiar assinatura.
  5. No modelo Clássico (sem foto) não é preciso carregar nada: as imagens comuns já lá estão.
3 · Se algo não aparecer
  • Imagem partida na pré-visualização: o GitHub Pages ainda está a publicar — espera mais uns minutos e carrega em Preencher outra vez.
  • Erro 404 ao abrir o endereço: confirma que as imagens estão na pasta docs/assinaturas do repositório tipiedade-leads, e não noutra pasta.
  • Nome de ficheiro diferente: o GitHub distingue maiúsculas e minúsculas. Logo.png não é o mesmo que logo.png.
  • Mudaste o nome da pessoa depois de carregar a foto: carrega em Preencher para acertar o endereço, ou volta a carregar a foto com o nome novo.
  • Trocar uma imagem (ex.: novo banner): carrega o ficheiro novo com o mesmo nome no repositório. As assinaturas já instaladas atualizam-se sozinhas.
